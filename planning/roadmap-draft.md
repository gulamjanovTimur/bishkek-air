# Черновик дорожной карты

Исходный набросок задач до grilling. Не публиковать как есть: /to-tickets нарежет вертикальные срезы сам. Используй как подсказку по объёму и критериям готовности.

### Контекст

- [ ] ESLint (typescript-eslint, react-hooks, импорт-порядок) + Prettier, нет предупреждений
- [ ] Vitest + React Testing Library + jsdom, один пример теста проходит
- [ ] Скрипты `dev`, `build`, `preview`, `lint`, `typecheck`, `test`, `format`

## Прокси к WAQI API и типизированный клиент

### Контекст
Токен WAQI не должен попадать в клиент (`docs/adr/0004-waqi-proxy-vercel-function.md`). Формат ответов и подводные камни — в разделе «Данные» `docs/ARCHITECTURE.md`.

### Критерии готовности
- [ ] Vercel Function `api/waqi/[...path].ts`: белый список путей (`map/bounds`, `feed/@<uid>/`), токен из `WAQI_TOKEN`, `Cache-Control: s-maxage=300, stale-while-revalidate=600`
- [ ] Ответ с ошибкой для неразрешённых путей и при `status: "error"` от WAQI
- [ ] Локально `/api/waqi/*` работает через proxy в `vite.config.ts` (токен подставляется на сервере)
- [ ] `shared/api/waqi`: функции `getStationsInBounds(bounds)` и `getStationFeed(uid)` с типами ответов и валидацией (zod или ручные type guards — решение зафиксировать в PR)
- [ ] Unit-тесты на разбор ответа: `aqi: "-"`, отсутствующие поля, ошибка API
- [ ] Проверено вручную: по границам Бишкека приходят станции (сколько — указать в PR)

## Станции на карте с цветом по AQI

### Контекст
Сценарий «Где сейчас грязно» из `planning/brief.md`. Шкала цветов — `docs/ARCHITECTURE.md`.

### Критерии готовности

- [ ] Компонентный тест с MSW: станции из мок-ответа попадают в source

## Кластеризация станций

### Контекст
В центре города датчики стоят плотно и перекрывают друг друга.

### Критерии готовности
- [ ] Кластеризация в GeoJSON source (`cluster: true`, подобрать `clusterRadius` / `clusterMaxZoom`)
- [ ] Кластер показывает количество станций; цвет кластера — по максимальному AQI внутри (`clusterProperties`)
- [ ] Клик по кластеру — плавное приближение до его раскрытия
- [ ] Курсор-указатель над кластерами и станциями

## Карточка станции и выбор через URL

### Контекст

- [ ] Мобильный вид — нижняя шторка
