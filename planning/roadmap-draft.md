# Черновик дорожной карты

Исходный набросок задач, уточнённый после grilling (решения — в `GLOSSARY.md`, `docs/ARCHITECTURE.md`, ADR 0005). Не публиковать как есть: /to-tickets нарежет вертикальные срезы сам. Используй как подсказку по объёму и критериям готовности.

**Порядок:** первый вертикальный срез (tracer bullet) — каркас → прокси → станции точками на карте → preview на Vercel. Деплой не откладываем на конец: прокси — это Vercel Function, и проверить его можно только там.

## Прокси к WAQI API и типизированный клиент

### Контекст
Токен WAQI не должен попадать в клиент (`docs/adr/0004-waqi-proxy-vercel-function.md`). Формат ответов и подводные камни — в разделе «Данные» `docs/ARCHITECTURE.md`.

### Критерии готовности
- [ ] Vercel Function `api/waqi/[...path].ts`: белый список путей (`map/bounds`, `feed/@<uid>/`), токен из `WAQI_TOKEN`, `Cache-Control: s-maxage=300, stale-while-revalidate=600`
- [ ] Ответ с ошибкой для неразрешённых путей и при `status: "error"` от WAQI
- [ ] Локально `/api/waqi/*` работает через proxy в `vite.config.ts` (токен подставляется на сервере)
- [ ] `shared/api/waqi`: функции `getStationsInBounds(bounds)` и `getStationFeed(uid)` с типами ответов и валидацией (zod или ручные type guards — решение зафиксировать в PR)
- [ ] Unit-тесты на разбор ответа: `aqi: "-"`, отсутствующие поля, погодные ключи в `iaqi`, ошибка API
- [ ] Проверено вручную: по границам Бишкека приходят станции. В PR указать, сколько их, сколько свежих и устаревших, и есть ли дубликаты из разных сетей

## Станции на карте с цветом по AQI

### Контекст
Сценарий «Где сейчас грязно» из `planning/brief.md`. Шкала цветов и свежесть данных — `docs/ARCHITECTURE.md`.

### Критерии готовности
- [ ] `entities/station`: доменный тип `Station`, маппер из ответа WAQI (отрезает хвост названия), хук `useStations()` на TanStack Query (staleTime 5 минут, 2 повтора)
- [ ] `entities/station`: вычисление свежести (`fresh` / `stale` / `no-data`, порог 3 часа из `shared/config`) + unit-тесты на границах порога
- [ ] `shared/lib/aqi`: `getAqiLevel(aqi)`, цвета и диапазоны + unit-тесты на границах (0, 50, 51, 100, 101, 300, 301, null). Подписи уровней — в словарях
- [ ] Станции — один GeoJSON source + circle layer, цвет через выражение MapLibre по уровню
- [ ] На точке `fresh` видно число AQI; точки `stale` и `no-data` серые, без числа, не ломают слой
- [ ] Состояния: загрузка (индикатор поверх карты), ошибка («Не удалось загрузить станции» + «Повторить»), 0 станций, все данные устарели
- [ ] Компонентный тест с MSW: станции из мок-ответа попадают в source

## Кластеризация станций

### Контекст
В центре города станции стоят плотно и перекрывают друг друга.

### Критерии готовности
- [ ] Кластеризация в GeoJSON source (`cluster: true`, подобрать `clusterRadius` / `clusterMaxZoom`)
- [ ] Кластер показывает количество станций; цвет — худший уровень среди `fresh` станций внутри (`clusterProperties`), без таких — серый
- [ ] Клик по кластеру — плавное приближение до его раскрытия
- [ ] Курсор-указатель над кластерами и станциями

## Карточка станции и выбор через URL

### Контекст
Сценарии «Мой район» и «Поделиться» из `planning/brief.md`. Состояние выбора — в URL (`docs/adr/0003-tanstack-query-and-url-state.md`).

### Критерии готовности
- [ ] `features/select-station`: хук чтения/записи `?station=<uid>` (replace, не push)
- [ ] Клик по станции на карте выбирает её; выбранная станция визуально выделена
- [ ] Панель при выборе переключается со списка на карточку; «← Ко всем станциям» и Esc снимают выбор и убирают параметр из URL
- [ ] Карточка: название; AQI крупно с цветом и текстом уровня; основной загрязнитель; индексы шести загрязнителей с подписью, что это индексы AQI; время обновления («12 минут назад», абсолютное по Asia/Bishkek в `title`); источники станции со ссылками
- [ ] `stale`: последнее значение с пометкой «данные от <дата, время>»
- [ ] Детали грузятся через `useStation(uid)`: скелетон, ошибка + «Повторить», «Станция не найдена» + «Ко всем станциям»
- [ ] Открытие ссылки с `?station=` сразу показывает карточку и перелетает к станции на зум, где кластеры раскрыты
- [ ] Мобильный вид: шторка переходит в `half`, точка сдвигается в видимую часть карты

## Список станций, синхронизированный с картой

### Контекст
Сценарий «Сравнение» из `planning/brief.md`. Это же клавиатурный путь к станциям.

### Критерии готовности
- [ ] `widgets/stations-table` на TanStack Table: название, AQI (с цветом), уровень, время обновления
- [ ] Группы всегда в порядке `fresh` → `stale` → `no-data`; внутри по умолчанию AQI ↓, `no-data` — по названию; у `stale` пометка «устарели»

- [ ] Мобильный `peek`: строка «хуже всего сейчас: <станция>, AQI» (худшая среди `fresh`)
- [ ] Клавиатурный путь: Tab → поиск → строки → Enter → карточка → Esc
