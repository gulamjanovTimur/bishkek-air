# Черновик дорожной карты

Исходный набросок задач, уточнённый после grilling (решения — в `GLOSSARY.md`, `docs/ARCHITECTURE.md`, ADR 0006–0008). Не публиковать как есть: /to-tickets нарежет вертикальные срезы сам. Используй как подсказку по объёму и критериям готовности.

**Порядок:** первый вертикальный срез (tracer bullet) — каркас Next → серверный слой WAQI → станции точками на карте → preview на Vercel. Деплой не откладываем на конец: серверный слой и кэш проверяются по-настоящему только на Vercel.

## Серверный слой WAQI и доменные эндпоинты

### Контекст
Токен и формат WAQI живут только на сервере (ADR 0007). Формат ответов и подводные камни — в разделе «Данные» `docs/ARCHITECTURE.md`.

### Критерии готовности
- [ ] `shared/api/waqi` (`server-only`): http-клиент с `WAQI_TOKEN` и базовым URL из `WAQI_BASE_URL` (по умолчанию `https://api.waqi.info`), `fetch(..., { next: { revalidate: 300 } })`, типы ответов и валидация (zod или ручные type guards — решение зафиксировать в PR); `status: "error"` превращается в ошибку
- [ ] `entities/station/server` (`server-only`): `getBishkekStations()` и `getStationDetails(uid)` возвращают доменные типы (маппер: хвост названия, `aqi: "-"`, только шесть загрязнителей, `sources`)
- [ ] Route Handlers `app/api/stations/route.ts` и `app/api/stations/[uid]/route.ts`: доменный формат, `Cache-Control: s-maxage=300, stale-while-revalidate=600`, коды `400` / `404` / `502`
- [ ] JSON-фикстуры ответов WAQI (`map/bounds`, `feed`) в репозитории — общие для unit- и e2e-тестов
- [ ] Unit-тесты маппера: `aqi: "-"`, отсутствующие поля, погодные ключи в `iaqi`, хвост названия
- [ ] Тесты Route Handlers с замоканным `fetch`: успех, `status: "error"`, невалидный ответ, `404`
- [ ] Проверено вручную: по границам Бишкека приходят станции. В PR указать, сколько их, сколько свежих и устаревших, и есть ли дубликаты из разных сетей

## Станции на карте с цветом по AQI

### Контекст
Сценарий «Где сейчас грязно» из `planning/brief.md`. Шкала цветов и свежесть данных — `docs/ARCHITECTURE.md`.

### Критерии готовности
- [ ] `entities/station/api`: хук `useStations()` → `/api/stations` на TanStack Query (staleTime 5 минут, 2 повтора)
- [ ] Страница предзагружает список на сервере и передаёт через `dehydrate` + `HydrationBoundary`; список приходит в HTML
- [ ] `entities/station/model`: вычисление свежести (`fresh` / `stale` / `no-data`, порог 3 часа из `shared/config`) + unit-тесты на границах порога. «Сейчас» — одно значение: сервер фиксирует `now` запроса и передаёт клиенту (next-intl `now` + свежесть), дальше `now` = `dataUpdatedAt`; нет hydration mismatch, нет таймеров
- [ ] `shared/lib/aqi`: `getAqiLevel(aqi)`, цвета и диапазоны + unit-тесты на границах (0, 50, 51, 100, 101, 300, 301, null). Подписи уровней — в словарях
- [ ] Станции — один GeoJSON source + circle layer, цвет через выражение MapLibre по уровню
- [ ] На точке `fresh` видно число AQI; точки `stale` и `no-data` серые, без числа, не ломают слой
- [ ] Состояния: загрузка (индикатор поверх карты), ошибка («Не удалось загрузить станции» + «Повторить»), 0 станций, все данные устарели. Падение серверной предзагрузки не роняет страницу
- [ ] Компонентный тест с MSW (`/api/stations`): станции из мок-ответа попадают в source

## Кластеризация станций

### Контекст
В центре города станции стоят плотно и перекрывают друг друга.

### Критерии готовности
- [ ] Кластеризация в GeoJSON source (`cluster: true`, подобрать `clusterRadius` / `clusterMaxZoom`)
- [ ] Кластер показывает количество станций; цвет — худший уровень среди `fresh` станций внутри (`clusterProperties`), без таких — серый
- [ ] Клик по кластеру — плавное приближение до его раскрытия
- [ ] Курсор-указатель над кластерами и станциями

## Карточка станции, выбор через URL и превью ссылки

### Контекст
Сценарии «Мой район» и «Поделиться» из `planning/brief.md`. Состояние выбора — в URL (`docs/adr/0003-tanstack-query-and-url-state.md`).

### Критерии готовности
- [ ] `features/select-station`: `?station=<uid>` через nuqs (`parseAsInteger`, replace, shallow — без серверного рендера при выборе)
- [ ] Клик по станции на карте выбирает её; выбранная станция визуально выделена
- [ ] Панель при выборе переключается со списка на карточку; «← Ко всем станциям» и Esc снимают выбор и убирают параметр из URL
- [ ] Карточка: название; AQI крупно с цветом и текстом уровня; основной загрязнитель; индексы шести загрязнителей с подписью, что это индексы AQI; время обновления («12 минут назад», абсолютное по Asia/Bishkek в `title`); источники станции со ссылками
- [ ] `stale`: последнее значение с пометкой «данные от <дата, время>»
- [ ] Детали грузятся через `useStation(uid)` → `/api/stations/[uid]`: скелетон, ошибка + «Повторить», «Станция не найдена» (`404`) + «Ко всем станциям»
- [ ] Открытие ссылки с `?station=`: детали предзагружены на сервере, карточка в HTML, карта перелетает к станции на зум, где кластеры раскрыты
- [ ] `generateMetadata`: `title` и OG-описание «<станция> — AQI <n>, <уровень>» на языке пользователя; без станции — общие
- [ ] Мобильный вид: шторка переходит в `half`, точка сдвигается в видимую часть карты
