# Бэклог после MVP

Превратить в issues, когда дойдёт очередь.

- **Прогноз PM2.5** — график прогноза по дням в карточке станции (`forecast.daily` из WAQI). Вернуть `forecast` в доменную модель, выбрать лёгкую библиотеку графиков или нарисовать на SVG, размер бандла указать в PR.
- **Исследование: история показателей** — WAQI API не отдаёт историю. Проверить OpenAQ v3 и другие источники для Бишкека, результат — ADR с решением.
- **Ближайшая станция** — по геолокации найти и предложить ближайшую станцию со свежими данными.
- **Русские названия станций** — словарь переводов для известных станций, чтобы поиск «посольство» находил US Embassy. Решать после ручной проверки списка станций.
- **Дедупликация станций** — если при проверке прокси найдутся станции, которые приходят из двух сетей.
- **Мобильная версия: шлифовка** — проверка на реальных устройствах, жесты перетаскивания шторки.
- **Производительность** — оптимизации по результатам замера MVP (размер клиентских чанков, стриминг панели через Suspense), итог «до/после» в README. Заводится, если замер ниже целей.
- **Автообновление** — `refetchInterval` при видимой вкладке.
- **Сравнение двух станций.**
- **Тёмная тема** — настройка пользователя в cookie (ADR 0008).
- **Кыргызский язык** — третий словарь, нужен переводчик для рекомендаций.
- **Статья** о проекте (Habr / dev.to).
