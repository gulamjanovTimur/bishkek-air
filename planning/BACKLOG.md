# Бэклог после MVP

Превратить в issues, когда дойдёт очередь.

- **Прогноз PM2.5** — график прогноза по дням в карточке станции (`forecast.daily` из WAQI). Выбрать лёгкую библиотеку графиков или нарисовать на SVG; размер бандла — в PR.
- **Исследование: история показателей** — WAQI API не отдаёт историю. Проверить OpenAQ v3 и другие источники для Бишкека; результат — ADR с решением.
- **E2E на Playwright** — сценарий: открыть сайт → увидеть станции → выбрать станцию → открыть ссылку в новой вкладке → та же станция. Запуск в CI.
- **Мобильная версия** — проверка на реальных устройствах, жесты шторки, размеры тач-целей.
- **Производительность** — замеры (Lighthouse, размер бандла), ленивые чанки для карты/таблицы, итог «до/после» в README.
- **Автообновление** — `refetchInterval` при видимой вкладке, индикатор «обновлено N минут назад».
- **Сравнение двух станций.**
- **Тёмная тема** и **английский интерфейс.**
- **Статья** о проекте (Habr / dev.to).
