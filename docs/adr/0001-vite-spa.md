# 1. SPA на Vite вместо Next.js

**Статус:** принято

## Контекст
Приложение — одна интерактивная страница с картой. SEO почти не важен, контент полностью зависит от данных в реальном времени. Нужен один небольшой серверный кусок — прокси к WAQI, чтобы спрятать токен.

## Решение
SPA на Vite + React. Серверная часть — одна Vercel Function в папке `api/`.

## Последствия
- Простая сборка, быстрый dev-сервер, меньше «магии» фреймворка.
- Нет SSR: первый экран — каркас и скелетоны, данные догружаются на клиенте.
- Если позже понадобятся SEO-страницы станций, можно пересмотреть в пользу Next.js (новый ADR).
