# 3. TanStack Query + URL вместо глобального стора

**Статус:** принято, дополнено ADR 0005 (настройки пользователя — в localStorage)

## Контекст
Почти всё состояние приложения — это данные с сервера (станции, детали). Из клиентского состояния — выбранная станция и фильтры, которые нужно синхронизировать между картой, таблицей и панелью и которыми удобно делиться ссылкой.

## Решение
- Серверное состояние — TanStack Query.
- Выбранная станция и фильтры — URL search params.
- Остальное — локальный `useState`.
- Глобальный стор (Zustand/Redux) не добавляем, пока не появится состояние, которое не укладывается в эти три категории.

## Последствия
- Ссылка восстанавливает состояние экрана.
- Нет дублирования серверных данных в сторе и ручной инвалидации.
- Нужно аккуратно работать с URL (замена истории вместо push при частых изменениях).
