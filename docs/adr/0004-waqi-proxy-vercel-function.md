# 4. Прокси к WAQI через Vercel Function

**Статус:** заменено ADR 0007 (серверный слой с доменными эндпоинтами)

## Контекст
WAQI API требует токен. В клиентском бандле токен виден любому. Кроме того, при росте трафика запросы каждого пользователя напрямую в WAQI упрутся в лимиты.

## Решение
Serverless-функция `api/waqi/[...path].ts` проксирует разрешённые пути (`map/bounds`, `feed/@<uid>/`) к `https://api.waqi.info`, подставляет `WAQI_TOKEN` из окружения и ставит `Cache-Control: s-maxage=300, stale-while-revalidate=600`.
Локально Vite dev server проксирует `/api/waqi` на WAQI, подставляя токен из `.env.local` в конфиге (на сервере, не в бандле).

## Последствия
- Токен не попадает в клиент и в git.
- CDN кэширует ответы — меньше запросов к WAQI, быстрее ответ.
- Белый список путей не даёт использовать прокси для произвольных запросов.
