# 2. MapLibre GL + OpenFreeMap вместо Mapbox

**Статус:** принято

## Контекст
Нужна векторная WebGL-карта с кластеризацией и стилизацией слоёв по данным. Mapbox GL JS v2+ требует токен и имеет платные лимиты; для открытого проекта это лишняя зависимость и секрет.

## Решение
MapLibre GL JS (открытый форк Mapbox GL v1) через `react-map-gl/maplibre`, подложка — бесплатные тайлы OpenFreeMap (стиль `liberty`).

## Последствия
- API почти совпадает с Mapbox GL: слои, источники, кластеризация, выражения для стилей.
- Нет токена для карты и лимитов по загрузкам.
- Зависим от доступности OpenFreeMap; URL стиля вынесен в `shared/config`, чтобы легко заменить провайдера.
