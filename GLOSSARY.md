# Глоссарий

Доменный язык Bishkek Air — карты качества воздуха в Бишкеке. Только смысл терминов, без деталей реализации. Английское название в скобках — канонический термин для кода и английской версии интерфейса.

## Станции

**Станция (Station)**:
Точка измерения качества воздуха с координатами и названием: государственный пост, станция сети (например, AirNet) или станция посольства США.
_Avoid_: датчик, сенсор, пост

**Станции Бишкека (Bishkek stations)**:
Станции, которые находятся в границах города. Станции пригородов (Кант, Сокулук, Ала-Арча) сюда не входят.

**Выбранная станция (Selected station)**:
Станция, которую пользователь сейчас рассматривает. Она одна на весь экран и восстанавливается по ссылке.

**Кластер (Cluster)**:
Группа близко расположенных станций, которую карта при отдалении показывает одним значком. Уровень кластера — худший уровень среди его станций со свежими данными.

## Показатели

**AQI (индекс качества воздуха)**:
Число по шкале US EPA, которое сводит загрязнение воздуха в один показатель. Чем выше, тем хуже. Общий AQI станции — это максимум индексов по её загрязнителям.

**Уровень AQI (AQI level)**:
Категория, в которую попадает AQI: хорошо (0–50), умеренно (51–100), вредно для чувствительных групп (101–150), вредно (151–200), очень вредно (201–300), опасно (301+). У каждого уровня есть свой цвет и рекомендация.

**Рекомендация (Guidance)**:
Короткое пояснение к уровню AQI, что делать людям на улице. Это перевод официальной формулировки US EPA / AirNow без собственных медицинских советов.

**Загрязнитель (Pollutant)**:
Одно из шести веществ, по которым считается AQI: PM2.5, PM10, NO₂, SO₂, O₃, CO. Погодные показатели (температура, влажность, давление, ветер) загрязнителями не являются.

**Индекс загрязнителя (Pollutant index)**:
AQI, посчитанный по одному загрязнителю. Это не концентрация (мкг/м³), а значение на той же шкале AQI.
_Avoid_: концентрация, значение загрязнителя

**Основной загрязнитель (Dominant pollutant)**:
Загрязнитель, по которому получился общий AQI станции, то есть загрязнитель с наибольшим индексом.

**Прогноз (Forecast)**:
Ожидаемые значения индекса загрязнителя по дням (минимум, среднее, максимум), если поставщик данных его отдаёт.

## Свежесть данных

**Время обновления (Last updated)**:
Момент последнего измерения станции, а не момент загрузки страницы. Показывается по времени Бишкека.

**Свежие данные (Fresh data)**:
Последнее измерение станции сделано не более 3 часов назад. Только свежие данные участвуют в раскраске карты и в сравнении станций.

**Устаревшие данные (Stale data)**:
Последнее измерение станции сделано более 3 часов назад. Последнее значение AQI известно, но не отражает текущий воздух: при сравнении и на карте станция считается как «нет данных», а в её карточке значение показано с датой.

**Нет данных (No data)**:
Станция существует, но значения AQI у неё нет. Это не «хорошо» и не ноль.

## Происхождение данных

**Поставщик данных (Data provider)**:
Сервис, из которого приложение получает все данные о станциях, — World Air Quality Index (WAQI). Указывается в интерфейсе всегда.
_Avoid_: источник, API

**Источник станции (Station source)**:
Организация, которая предоставила данные конкретной станции (например, AirNet или посольство США). Указывается в карточке станции всегда.
_Avoid_: «источник» без уточнения, attribution

## Интерфейс

**Список станций (Station list)**:
Таблица станций Бишкека с поиском по названию и сортировкой. Её показывает панель, пока ни одна станция не выбрана.

**Карточка станции (Station card)**:
Подробности о выбранной станции: AQI, уровень, загрязнители, время обновления и источники. Её показывает панель вместо списка станций, когда станция выбрана.
