# Глоссарий

Доменный язык проекта. Только смысл терминов — без деталей реализации.

**Станция (Station)** — точка измерения качества воздуха с координатами и названием: государственный пост, датчик сети или станция посольства. Синонимы «датчик», «сенсор» в продукте означают то же самое.

**AQI (индекс качества воздуха)** — число по шкале US EPA, которое сводит загрязнение воздуха в один показатель. Чем выше, тем хуже. У станции есть общий AQI — максимум по всем загрязнителям.

**Уровень AQI (AQI level)** — категория, в которую попадает AQI: хорошо (0–50), умеренно (51–100), вредно для чувствительных групп (101–150), вредно (151–200), очень вредно (201–300), опасно (301+). У каждого уровня свой цвет и рекомендация.

**Загрязнитель (Pollutant)** — вещество, которое измеряет станция: PM2.5, PM10, NO₂, SO₂, O₃, CO.

**Индекс загрязнителя** — AQI, посчитанный по одному загрязнителю. Это не концентрация (мкг/м³), а значение на той же шкале AQI.

**Основной загрязнитель (Dominant pollutant)** — загрязнитель, по которому получился общий AQI станции (с наибольшим индексом).

**Нет данных** — станция существует, но текущего значения AQI нет. Это не «хорошо» и не ноль.

**Время обновления** — момент последнего измерения станции по местному времени, а не момент загрузки страницы.

**Выбранная станция** — станция, которую пользователь сейчас рассматривает; одна на весь экран и восстанавливается по ссылке.

**Кластер** — группа близко расположенных станций, показанная на карте одним значком при отдалении. Уровень кластера — худший уровень среди его станций.

**Прогноз** — ожидаемые значения загрязнителя по дням (минимум, среднее, максимум), если источник его отдаёт.

**Источник (Attribution)** — организация, предоставившая данные станции; указывается всегда.
